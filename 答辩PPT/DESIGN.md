## 全局视觉约定

① 画布与安全区
- 1280×720；Slide padding 上 80 / 左右 60 / 下 60；内容区 x 60–1220、y 80–660（1160×580）
- 页眉 A3 深蓝顶条 y 0–72（绝对定位装饰，不占内容流）；顶条下 1px 中性细线（全篇唯一视觉母题）
- 页脚 y 670–690：左单位 14px 灰、右页码 14px 主蓝；封面 / 目录 / 致谢页省略页眉页脚

② 配色（academic 色板）
- 主色 `#1E4FA8`（顶条 / 编号 / 强调）；藏蓝 `#0E3F8C`；浅蓝卡底 `#F0F5FC` / `#E8EFF8`；中蓝 `#3D7BD9`
- 警示红 `#D9534F`（仅错误接法与风险，单页 ≤3%）；数据黄 `#FFC107`（仅图表第二序列）
- 文本 `#1A2230` / `#4A5568` / `#8B97A8`；线框 `#D6DCE5` / `#E5E7EB`；背景 `#FFFFFF` / `#F7F9FC`
- 蓝族 35–55%、白底 30–55%、红+黄 ≤5%、金色 0；C 区禁深色实底

③ 字体系统
- 中文 Microsoft YaHei（思源黑族）；西文 Arial / Times New Roman（仅封面英文长标题）
- 字号阶梯：封面中文 60 / 封面英文 26 / 页面主标 32 / 卡内标题 24 / 正文 22 / 表格 18–20 / KPI 72 / 注释与页脚 14–16
- 正文行高 1.5，卡内标题 1.25，主标题 1.15；同页文字样式 ≤4 种

④ 视觉母题
- 内容页统一「深蓝顶条 + 顶条下 1px 贯通细线 + 右下页码 0N / 10」；编号用浅蓝药丸，短色条禁用
